# Leverage Audit

## Purpose

Naval's framing of leverage distinguishes old-world levers — labor (requires managing people) and capital (requires permission from allocators) — from new-world levers — code (replicable software) and media (attention and distribution). Real estate is traditionally a labor-and-capital business, which caps its returns to the scale of the team and the patience of the allocators. This skill forces the crew to ask where code and media leverage can be added to any position, and to prefer positions that compound without permission.

## Protocol

### Step 1: Classify the Current Leverage Mix

State what fraction of the deal's expected return comes from each form of leverage:

- **Labor leverage** (asset managers, property managers, leasing teams, construction crews)
- **Capital leverage** (debt financing, LP equity, preferred equity)
- **Code leverage** (proprietary software for underwriting, leasing, operations, tenant experience)
- **Media leverage** (brand, distribution, owned audience that drives tenant or buyer demand)

For most real estate deals, the answer is 50%+ capital, 40%+ labor, close to zero code, close to zero media. That is the diagnosis.

### Step 2: Identify the Code Leverage Opportunity

Ask: what is the one repeatable software surface that would meaningfully change this deal's unit economics?

Common candidates: proprietary underwriting model, automated leasing funnel, digital tenant onboarding, predictive maintenance system, data platform for the asset class. The test is replicability — can the same system serve the next deal and the deal after that with marginal cost near zero?

If no code leverage is plausible, state why explicitly.

### Step 3: Identify the Media Leverage Opportunity

Ask: what is the audience this deal could build or tap that would generate distribution without paying for it each time?

Common candidates: owner-operated content about the neighborhood or asset class, a newsletter that captures qualified tenants or buyers, a community presence that makes the brand the default choice in the submarket, earned press on a signature project.

If no media leverage is plausible, state why explicitly.

### Step 4: Run the Permissionless Test

For each leverage form, state whether it requires permission:

- Labor: yes (people can quit)
- Capital: yes (allocators can pull)
- Code: no (once built, it runs)
- Media: no (once owned, it distributes)

A deal whose entire leverage stack requires permission is a deal whose growth requires continuously re-earning that permission. Acceptable for one deal, dangerous as a strategy.

### Step 5: Score the Holding on Accountability and Specific Knowledge

Naval: "Escape competition through authenticity." Ask:

- Is this deal using specific knowledge the operator actually has, or is it a commoditized transaction anyone with capital could do?
- Is the operator accountable under their own name for the results, or hiding inside a syndicate?
- Can the operator articulate what they see that the market does not?

If the answers are "commoditized / hidden / nothing specific," the deal is a bet on access to cheap capital rather than on insight.

### Step 6: Design the Compounding Layer

State one concrete addition — a tool, a product, a newsletter, a dataset, a brand — that would convert this single deal into an asset that makes the next deal easier. Without this layer, each deal starts from zero; with it, the portfolio compounds.

### Step 7: Write the Leverage Verdict

> "Current leverage mix: L[X]% C[Y]% Code[Z]% Media[W]%. Code opportunity: [what, cost, replicability]. Media opportunity: [what, audience, defensibility]. Specific knowledge: [what the operator sees that others do not]. Compounding layer: [named addition]. [Proceed with compounding layer in scope / proceed without / walk — no specific knowledge]."

## When to Apply

Every deal where the firm is making more than one bet in this asset class or submarket. A single one-off deal can be evaluated on conventional terms, but any repeatable strategy should be audited for permissionless leverage.

## When Not to Apply

One-off opportunistic trades where the firm has no intention of building a platform. Even here, note explicitly that the absence of compounding leverage is a choice.

## Integration With Other Skills

This skill addresses compounding survivability — whether the firm's advantage grows with time or must be reconstructed each deal.
