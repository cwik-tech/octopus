# Skill: Discussion Facilitation

## Purpose

Structured techniques for guiding multi-agent brainstorming sessions from divergent exploration to convergent synthesis.

## When to Use

At the start of every discussion round and when synthesizing final output.

## Method

### Framing (Round 1)

1. Restate the problem in your own words — confirm understanding before ideation.
2. Ask one open-ended question that invites wide-ranging responses.
3. Avoid leading questions that push toward a specific answer.

### Building (Rounds 2+)

1. Identify the 2-3 strongest threads from previous responses.
2. Name what connects them — surface the underlying pattern.
3. Ask a targeted follow-up that deepens the strongest thread.
4. If responses are converging too early, introduce a constraint flip: "What if [key assumption] were false?"

### Synthesizing (Final Round)

1. Group ideas into 2-4 clusters by theme.
2. For each cluster, name the core insight (not just the idea).
3. Rank by: impact potential first, feasibility second.
4. Identify gaps — what hasn't been explored that should be?

## Output

A structured summary with: problem statement, top ideas (ranked), key insights, and recommended next steps.
