# Investment Position Statement Template

```
## Position Statement: [Agent Name]

### Deal
[Company Name] — [Stage] — [Sector] — [Requested Raise] at [Valuation]

### Stance
[Invest / Pass / Conditional — in one sentence with the core reason]

### Evidence
1. [Data point 1 — specific, verifiable, sourced]
2. [Data point 2]
3. [Data point 3]
4. [Data point 4, if applicable]

### Reasoning
[2-3 sentences explaining HOW the evidence supports the stance.
Name the causal mechanism. Not "the numbers are good" but
"these metrics exceed stage benchmarks by X, which historically
correlates with Y outcome."]

### Key Assumption
[The single most important thing that must be true for this
stance to hold. If this assumption fails, the stance changes.]

### What Would Change My Mind
[Specific data, event, or argument that would shift this position.
Not vague — "if retention drops below 70% in the next cohort"
or "if the regulatory ruling in Q3 goes against the company."]

### Confidence Level
[High / Medium / Low — with one sentence explaining why]

### References to Other Agents
[Which other agents' positions does this interact with?
Where do you agree? Where do you clash? Name the tension.]

### Closing Question
[One question the committee must answer before making
a final decision, raised by your analysis.]
```

## Usage Notes

- Every field is mandatory. Incomplete position statements weaken committee deliberation.
- The "Key Assumption" field is the most important. It's the fragility point. Other agents should attack it.
- "What Would Change My Mind" prevents positions from becoming entrenched. If you can't articulate what would change your mind, your position is dogma, not analysis.
- Confidence Level is not politeness — it's calibration. Track it over time to improve judgment accuracy.
