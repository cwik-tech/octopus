# Ergonomics and Proportion

## Purpose

Establish dimensions that work for the intended users and look visually balanced in their environment.

## Method

1. Identify the primary activity: sitting, eating, working, storing, displaying, sleeping, or circulation.
2. Identify user population, accessibility needs, existing adjacent furniture, and room constraints.
3. Establish hard dimensions from the site and functional objects first.
4. Use common ergonomic ranges as starting points, then adjust for the specific user and task.
5. Check clearances for approach, legroom, drawer and door operation, seating movement, and cleaning access.
6. Evaluate visual proportion: top thickness, leg slenderness, overhang, rail depth, negative space, and relationship between large and small masses.
7. Flag any dimension outside a normal range and explain the purpose of the deviation.

## Practical Reference Ranges

Use these as starting points, not universal prescriptions:

| Application | Typical starting range |
| --- | --- |
| Dining or desk work surface | 28–30 in high |
| Dining chair seat height | 17–19 in high |
| Dining chair seat-to-top clearance | about 10–12 in |
| Coffee table height | 16–18 in high, generally near adjacent seat height |
| Kitchen counter | about 36 in high |
| Comfortable seated table depth per person | about 18–24 in |
| Basic walkway clearance | about 30–36 in, more where traffic is frequent |

## Proportion Checks

- Compare the visual thickness of tops to the scale of legs and aprons.
- Keep component sizes consistent with the piece's apparent load and style.
- Use repetition intentionally: related overhangs, reveal widths, rail depths, and panel margins create coherence.
- Test the design in elevation and plan view; a good front view can hide an awkward depth or clearance.
- When a dimension is driven by aesthetics rather than function, label it as a design choice.

## Output

State the user assumptions, key ergonomic dimensions, required clearances, proportion decisions, and any dimensions that must be verified on site.
