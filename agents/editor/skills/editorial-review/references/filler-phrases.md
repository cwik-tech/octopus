# Filler Phrases — Reference

Corporate filler that editors should flag during Layer 3 (Clarity and Concision) review. Severity rated 1-3.

**Severity 1:** Always flag and remove — adds no information, weakens credibility.
**Severity 2:** Usually flag — almost always has a stronger, specific alternative.
**Severity 3:** Sometimes flag — context-dependent, but usually a stronger option exists.

---

## Strategy and Direction Filler

| Phrase | Severity | Problem | Flag with |
|---|---|---|---|
| "leverage synergies" | 1 | Meaningless without specifics | "Name the specific synergy" |
| "strategic alignment" | 1 | What is aligned with what? | "Specify what is aligned and why it matters" |
| "holistic approach" | 1 | What does 'holistic' mean here? | "Name the components of the approach" |
| "drive value" | 1 | What value? For whom? | "Specify the value: reduce costs by X / increase revenue by Y" |
| "move the needle" | 1 | Which needle? By how much? | "Name the metric and expected change" |
| "transformational" | 2 | Overused superlative | "Describe what specifically transforms" |
| "game-changer" | 2 | Unsubstantiated | "Describe the specific change and its magnitude" |
| "paradigm shift" | 2 | Consultant cliché | "Describe what changes and why it's significant" |
| "disruptive" | 2 | Overused | "Describe the disruption specifically" |
| "innovative" | 2 | Means nothing without context | "Describe the innovation" |

## Process and Action Filler

| Phrase | Severity | Problem | Flag with |
|---|---|---|---|
| "going forward" | 1 | Redundant — context implies future | Delete |
| "at this point in time" | 1 | Redundant — "now" suffices | Replace with "now" or "currently" |
| "on a going-forward basis" | 1 | Redundant | Delete |
| "touch base" | 1 | Jargon | "Meet / call / discuss" |
| "circle back" | 1 | Jargon | "Revisit / return to / follow up" |
| "reach out" | 2 | Jargon | "Contact / call / email" |
| "ping" (in formal docs) | 2 | Informal jargon | "Contact / message / notify" |
| "action" as a verb ("action this") | 2 | Jargon | "Complete / execute / implement" |
| "socialise" (an idea) | 2 | Jargon | "Share / discuss / present" |
| "operationalise" | 2 | Jargon | "Implement / execute / put into practice" |
| "deep dive" | 2 | Overused | "Detailed analysis / thorough review" |
| "unpack" | 2 | Informal | "Analyse / examine / explore" |

## Emphasis Filler

| Phrase | Severity | Problem | Flag with |
|---|---|---|---|
| "it should be noted that" | 1 | Empty preamble | Delete — just state the thing |
| "it is important to note that" | 1 | Empty preamble | Delete — everything in the doc is important |
| "it is worth mentioning that" | 1 | Empty preamble | Delete |
| "needless to say" | 1 | Contradiction — if needless, don't say it | Delete the sentence or keep without preamble |
| "clearly" | 2 | Condescending if the reader doesn't find it clear | Delete or prove it |
| "obviously" | 2 | Condescending | Delete |
| "of course" | 2 | Often patronising | Delete |
| "key" (overused) | 2 | Loses meaning when everything is "key" | Reserve for genuinely critical items only |
| "critical" (overused) | 3 | Loses meaning | Use sparingly — one or two per document maximum |
| "fundamental" | 3 | Overused | Describe why it's fundamental |

## Vague Quantifiers (always replace with numbers when available)

| Phrase | Replace with |
|---|---|
| "significant increase/decrease" | The percentage or absolute change |
| "substantial growth" | The growth rate |
| "considerable improvement" | The metric and improvement |
| "various stakeholders" | The specific groups |
| "numerous factors" | The count and list |
| "a number of" | The actual number |
| "many customers" | The count or percentage |
| "most clients" | The percentage |
| "some teams" | Which teams |
| "in the near future" | The specific date or quarter |
| "soon" | When |
| "recently" | When (specific date or period) |
