# Engagement Benchmarks

## Purpose

Engagement benchmarks by product type, stage, and category. Use to evaluate whether a startup's user engagement indicates genuine product value or superficial usage.

---

## DAU/MAU Ratio (Daily Active Users / Monthly Active Users)

The most widely used engagement metric. Indicates what percentage of monthly users use the product daily.

| Product Type | Low | Average | Good | Exceptional |
|---|---|---|---|---|
| Social media | <20% | 20-35% | 35-50% | >50% (Facebook-level) |
| Messaging / communication | <25% | 25-40% | 40-55% | >55% |
| B2B SaaS (workflow tool) | <15% | 15-25% | 25-40% | >40% |
| B2B SaaS (analytics/reporting) | <8% | 8-15% | 15-25% | >25% |
| Consumer subscription (content) | <10% | 10-20% | 20-30% | >30% |
| Marketplace (buyer side) | <5% | 5-10% | 10-20% | >20% |
| Fintech (banking/payments) | <8% | 8-15% | 15-25% | >25% |
| Health / fitness | <10% | 10-20% | 20-35% | >35% |
| Productivity tools | <15% | 15-25% | 25-40% | >40% |

**Interpretation caveat:** DAU/MAU is not meaningful for products that aren't designed for daily use. A tax preparation tool used once a year has 0% DAU/MAU but could have excellent engagement when measured appropriately.

## Session Metrics

### Session Frequency (sessions per week)

| Product Type | Low | Average | Good | Exceptional |
|---|---|---|---|---|
| Social / messaging | <3 | 3-7 | 7-14 | >14 (multiple daily) |
| B2B SaaS (daily workflow) | <3 | 3-5 | 5-7 | >7 |
| B2B SaaS (weekly tool) | <1 | 1-2 | 2-3 | >3 |
| Consumer app | <2 | 2-4 | 4-7 | >7 |
| Marketplace | <1 | 1-2 | 2-4 | >4 |

| Product Type | Low | Average | Good | Exceptional |
|---|---|---|---|---|

## Feature Adoption

### Breadth of Feature Usage

| Metric | Low | Average | Good | Exceptional |
|---|---|---|---|---|
| % of features used by average user | <10% | 10-25% | 25-50% | >50% |
| % of users who use 3+ features | <20% | 20-40% | 40-60% | >60% |

**Interpretation:** Low feature adoption can mean either the product has unnecessary features (over-built) or users haven't discovered the value (onboarding problem). High feature adoption indicates broad value delivery and higher switching costs.

### Core Feature Engagement

More important than overall feature adoption is engagement with the *core value feature* — the single feature that delivers the product's primary value proposition.

| Signal | Assessment |
|---|---|
| >80% of users engage with core feature weekly | Strong — the core value proposition works |
| 50-80% engage with core feature weekly | Moderate — some users aren't finding value |
| <50% engage with core feature weekly | Weak — product may not be delivering on promise |

---

## Time to Value (TTV)

How quickly new users reach the "aha moment" — the point where they experience the product's core value.

| Product Type | Good TTV | Target |
|---|---|---|
| Consumer app | <5 minutes | First session |
| Self-serve SaaS | <1 day | First day |
| SMB SaaS | <1 week | First week |
| Mid-market SaaS | <2 weeks | Within trial period |
| Enterprise SaaS | <30 days | Within POC period |

**Rule of thumb:** If TTV is longer than the free trial or POC period, conversion will suffer dramatically.

## Power User Analysis

### Power User Ratio

What percentage of active users are "power users" (top 10% by engagement)?

| Distribution | Assessment |
|---|---|
| Power users account for >80% of usage | Risky — product only works for a few, most users are disengaged |
| Power users account for 40-60% of usage | Healthy — engaged core with moderate general usage |
| Power users account for <30% of usage | Strong — value is distributed broadly across users |

### Power User Characteristics

Understanding *who* the power users are reveals whether the product can grow:
- If power users are a specific persona that's easy to find → Acquisition can be targeted
- If power users have no common pattern → Product-market fit may be accidental
- If power users are all from the same company → Customer concentration risk

## Stickiness Indicators

### Net Promoter Score (NPS) Benchmarks

| NPS Range | Assessment |
|---|---|
| <0 | Detractors outnumber promoters — significant product or experience issues |
| 0-30 | Acceptable — room for improvement |
| 30-50 | Good — customers are generally satisfied |
| 50-70 | Excellent — strong word-of-mouth potential |
| >70 | Exceptional — rare, indicates extraordinary product-market fit |

**B2B SaaS average NPS:** 30-40
**Consumer app average NPS:** 20-30

### Viral Coefficient (K-Factor)

| K-Factor | Assessment |
|---|---|
| <0.2 | No meaningful virality |
| 0.2-0.5 | Some organic sharing, supplements paid acquisition |
| 0.5-0.8 | Strong virality — meaningful growth driver |
| 0.8-1.0 | Near-viral — approaching self-sustaining growth |
| >1.0 | Truly viral — each user brings in more than one new user (rare and usually temporary) |
