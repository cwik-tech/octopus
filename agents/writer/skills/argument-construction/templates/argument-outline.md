## Argument Health Check

Before handing to the Writer, confirm:

- [ ] Governing thought is specific and answers the key question
- [ ] Every section's key point supports the governing thought
- [ ] Every supporting point backs its section's key point
- [ ] No section could be removed without weakening the overall argument
- [ ] If using MECE: options/categories are tested for overlap and exhaustiveness
- [ ] If using SCR: resolution directly addresses the complication
- [ ] Executive summary can stand alone as a complete answer
