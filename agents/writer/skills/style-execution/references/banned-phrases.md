# Banned Phrases — Reference

Corporate filler, vague language, and weak constructions that consistently weaken business writing. Organised by severity.

---

## Severity 1 — Always Remove

These phrases add no information and actively weaken the writing. Delete on sight.

| Phrase | Why it fails | Replace with |
|---|---|---|
| "leverage synergies" | Means nothing without specifics | Name the specific synergy: "combine X's distribution with Y's product" |
| "holistic approach" | What's holistic about it? | Name the components: "covering strategy, operations, and technology" |
| "best-in-class" | Unsubstantiated superlative | Cite the benchmark or remove it |
| "move the needle" | Vague impact language | State the metric and the expected change |
| "drive value" | What value, for whom, how? | "Reduce processing time by 40%" or "increase revenue by £500K" |
| "strategic alignment" | Filler between two things | Say what is aligned with what and why it matters |
| "going forward" | Unnecessary — context implies the future | Delete. "Going forward, we will..." → "We will..." |
| "at the end of the day" | Spoken filler, not written | Delete entirely |
| "it should be noted that" | Empty introduction | Delete. Just state the thing. |
| "it is important to note that" | Weak preamble | Delete. If it's in the document, it's already important. |
| "in terms of" | Wordy preposition | Replace with "for," "regarding," or restructure the sentence |
| "touch base" | Jargon | "Meet," "call," "discuss" |
| "circle back" | Jargon | "Revisit," "return to," "follow up" |
| "bandwidth" (for capacity) | Tech jargon leaking into consulting | "Capacity," "time," "resource availability" |
| "deep dive" | Overused | "Detailed analysis," "thorough review" |
| "low-hanging fruit" | Cliché | "Quick wins," "immediate opportunities" — or name the specific action |
| "pain points" | Overused | "Challenges," "obstacles," "friction" — or name the specific problem |
| "value-add" | Usually redundant | Either something adds value or it doesn't. Name what it adds. |
| "boil the ocean" | Cliché | "Attempt too much at once" or "pursue an exhaustive scope" |
| "move fast and break things" | Startup cliché | Not appropriate in consulting documents |

---

## Severity 2 — Replace When Possible

These phrases are not always wrong, but they often indicate a stronger, more specific statement is available.

| Phrase | Problem | Better alternative |
|---|---|---|
| "significant" | Vague quantifier | Use the number: "a 34% increase" |
| "substantial" | Vague quantifier | Quantify or specify |
| "considerable" | Vague quantifier | Quantify or specify |
| "various" | Vague | "Three," "multiple," or list them |
| "numerous" | Vague | "Seven," "many," or list them |
| "very" | Weak intensifier | Remove — if the thing is important, the word itself should carry it |
| "quite" | Undermining qualifier | Remove or strengthen the claim |
| "somewhat" | Hedging without meaning | Commit to the claim or acknowledge uncertainty explicitly |
| "fairly" | Weak | Remove or strengthen |
| "rather" | Vague modifier | Remove or be specific |
| "things" | Non-specific | Name the things |
| "stuff" | Informal, non-specific | Name the things |
| "issues" | Overused | "Challenges," "problems," "risks" — name them specifically |
| "challenges" | Overused | Name the specific challenge |
| "stakeholders" | Vague | Name the groups: "the board," "the sales team," "external clients" |
| "key" (overused) | Often meaningless | "Key finding" → "The primary finding." Reserve "key" for genuinely critical items. |
| "robust" | Consulting cliché | "Comprehensive," "well-structured," or describe what makes it robust |
| "innovative" | Overused | Describe the innovation specifically |
| "cutting-edge" | Overused superlative | Describe the specific capability |
| "world-class" | Unsubstantiated | Cite the benchmark |

---

## Severity 3 — Flag and Discuss

These constructions are sometimes appropriate but often indicate a stronger alternative exists.

| Construction | When it's a problem | Better approach |
|---|---|---|
| "It was decided that..." | Passive hides who decided | "[Person / group] decided to..." |
| "Mistakes were made" | Classic evasion | Name who made the mistake or say "the team encountered X" |
| "There are a number of..." | Weak sentence opener | Start with the noun: "Three factors..." |
| "Due to the fact that" | Wordy | "Because" |
| "In order to" | Wordy | "To" |
| "As a result of" | Wordy | "Because of" or restructure |
| "In the event that" | Wordy | "If" |
| "At this point in time" | Wordy | "Now" or "currently" |
| "On a going-forward basis" | Wordy filler | Delete or use "from now on" |
| "The reason why is because" | Redundant | "Because" |
| Noun chains ("the implementation of the transformation of the organisation") | Unreadable | "Transforming the organisation" |

## Abbreviation Policy (per style guide)

Always define abbreviations on first use. Write the full term first, followed by the abbreviation in parentheses. After definition, use the abbreviation freely.

**Example:** "The company's Customer Acquisition Cost (CAC) has risen 40% year-over-year. This CAC increase reflects the longer enterprise sales cycle."

**Exception — universally known abbreviations (no definition needed in business documents):**
CEO, CFO, COO, CTO, CMO, VP, ROI, KPI, Q1/Q2/Q3/Q4, UK, EU, US, IT, HR, PR, B2B, B2C
