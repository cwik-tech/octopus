# Tool-Aware Method Selection

## Purpose

Choose methods a builder can execute safely and repeatably with their actual shop capability.

## Procedure

1. Define the operation: cut, joint, shape, drill, edge treatment, or assembly.
2. Identify requirements: strength, appearance, tolerance, repeat count, material, and finish sensitivity.
3. Inventory available tools, workholding, measurement tools, space, and operator experience.
4. Compare feasible methods on safety, setup time, repeatability, material risk, and cleanup effort.
5. Recommend a primary method and one simpler fallback when practical.
6. State required test cuts, reference surfaces, and stop points before irreversible operations.

## Selection Rules

- Prefer a controlled setup over freehand precision.
- Prefer a router table, drill press, sled, fence, or jig when it materially improves repeatability.
- Use hand tools for fitting, cleanup, and low-volume precision where machine setup is disproportionate.
- Recommend outsourcing only when required accuracy, capacity, tooling, or safety exceeds a reasonable home shop.
- Do not prescribe a method without naming its workholding and reference strategy.

## Output

Provide method, tools, setup sequence, critical dimensions, safety controls, test-piece plan, and fallback option.
