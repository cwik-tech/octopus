# Argument Construction Skill

## When to Use

Use this when drafting the final `output/investment-memo.md`.

## Default Framework

Use Pyramid Principle unless the template forces a narrower section pattern:

1. state the recommendation first
2. group supporting reasons cleanly
3. support each reason with evidence
4. state the implication for the investment decision

## Section Logic

For each major memo section:

- make a claim
- back it with observed evidence from the minutes or source materials
- explain why the claim matters to the recommendation
- surface the limiting factor or unresolved diligence question

## Data Narration Rules

- do not present raw numbers without interpretation
- compare projections against operational reality when the board challenged them
- separate observed fact, reasoned inference, and recommendation
- if evidence is thin, score and frame conservatively

## Memo Discipline

- preserve criterion-by-criterion judgment
- do not average away real tensions
- convert unresolved tensions into risks, conditions, or diligence actions
- do not let strong founder narrative inflate unrelated sections
