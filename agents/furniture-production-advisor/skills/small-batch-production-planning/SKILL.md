# Small-Batch Production Planning

## Purpose

Convert a proven furniture design into a practical, low-risk small-batch production plan for a home or small shop.

## Process

1. Define the reference unit: dimensions, materials, hardware, finish, and acceptable variation.
2. Map the build into operations: milling, cutting, joinery, dry fit, glue-up, shaping, sanding, finishing, packing.
3. Identify constraints: machine capacity, clamps, bench space, drying space, material lead time, storage, and available hours.
4. Separate work into batchable operations and unit-specific operations.
5. Choose the smallest batch that improves efficiency without exceeding space, cash, or quality-control capacity.
6. Specify staging, labels, part counts, jigs, and stop blocks needed before starting.
7. Include buffers for defects, rework, finish curing, and delivery.

## Planning Rules

- Pilot with two to five units before committing to a larger batch.
- Batch stable, repeatable operations; avoid batching steps that make part identification difficult.
- Build and test jigs before production material is cut.
- Preserve a first-article unit or documented reference for comparison.
- Treat finishing and curing space as production constraints, not afterthoughts.

## Output

Provide a table with operations, batch method, dependencies, equipment, quality checkpoint, time estimate, and primary risk. End with a recommended pilot batch size and go/no-go conditions.
