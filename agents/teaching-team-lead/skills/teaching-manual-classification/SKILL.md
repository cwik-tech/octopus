# Teaching Manual Classification

## Purpose

Upfront classification of the teaching material to determine specialist needs, anticipate conflicts between pedagogical and technical reviewers, and set the frame for coordinated review.

## Classification Framework

### Manual Types

**Introductory Guide**
- Assumes minimal prior knowledge
- Prioritizes conceptual foundations and engagement
- Technical accuracy is important but not the primary constraint
- Success = reader understands the core concepts and wants to learn more

**Advanced Technical Reference**
- Assumes intermediate or expert audience
- Prioritizes completeness, precision, and technical depth
- Pedagogical flow is secondary to technical accuracy
- Success = reader can reference and apply advanced concepts

**Procedural Guide**
- Teaches a sequence of steps or process
- Prioritizes clarity of sequence, prerequisites, and decision points
- Both pedagogical flow (when to do what) and technical accuracy (how to do it correctly) matter
- Success = reader can execute the procedure correctly

**Conceptual Framework**
- Teaches a model, theory, or system of understanding
- Prioritizes logical consistency and coherence
- Technical accuracy in the framework itself is paramount
- Success = reader internalizes the framework and can apply it

**Reference Manual**
- Designed for lookup, not linear reading
- Prioritizes organization, indexing, and precision
- Pedagogical flow is less critical; discoverability is paramount
- Success = reader can find and understand the information they need when they need it

### Learning Context

For each manual, identify:

1. **Target Audience:** Who is learning? (Students, practitioners, domain-adjacent professionals, decision-makers)
2. **Prior Knowledge:** What must they already know to benefit?
3. **Learning Goals:** What should they be able to do, think, or understand after working through the manual?
4. **Use Context:** When and how will they use this material? (In a classroom, self-paced at home, as reference during work, etc.)
5. **Success Metrics:** How will we know the manual worked? (Quiz performance, procedural success, conceptual understanding, user satisfaction)

### Potential Conflict Areas

Certain manual types create predictable tension between pedagogical and technical reviewers:

| Manual Type | Pedagogical Priority | Technical Priority | Common Tension |
|---|---|---|---|
| Introductory | Conceptual clarity, engagement | Accuracy, precision | Depth vs. simplicity: intro materials may sacrifice technical detail for understanding |
| Advanced Technical | Advanced pedagogy (scaffolding to expert thinking) | Completeness, precision | Speed vs. rigor: experts want depth; learners need intermediate scaffolds |
| Procedural | Sequence clarity, decision points | Step accuracy, edge cases | What users need to know vs. what can go wrong: pedagogy focuses on happy path; technical review flags exceptions |
| Conceptual | Internal coherence, intuitive model | Formal correctness of framework | Intuitive clarity vs. technical precision: metaphors may conflict with strict definitions |
| Reference | Discoverability, scannability | Precision, completeness | Organization vs. detail: pedagogy optimizes for quick scanning; technical review wants full accuracy even if longer |

## Classification Process

1. **Identify manual type:** Which category best fits this material?
2. **Profile the audience:** Who is learning, and what do they already know?
3. **State learning goals:** What should they know or be able to do?
4. **Name use context:** When will they use this?
5. **Identify tensions:** Which pedagogical-technical tradeoffs are most likely in this type?
6. **Determine specialist focus:** Which reviewer should pay closest attention to which dimension?

## Output

Classification summary with:
- Manual type and why it fits that category
- Target audience and prior knowledge assumptions
- Learning goals (3-5 key outcomes)
- Use context (when and how the material will be used)
- Predicted pedagogical-technical tensions
- Recommended specialist focus areas
