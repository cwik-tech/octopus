# Per-video methodology contract

Each source method must be independently usable and auditable. Include source metadata, intended outcome, prerequisites, ordered steps, decision points, named tools, examples, metrics, failure modes, caveats, ambiguities, and timestamped provenance.

Use these evidence labels where interpretation matters:

- `Source states` for a claim directly supported by the transcript.
- `Source demonstrates` for an example shown or narrated.
- `Interpretation` for a reasonable implication not explicitly stated.
- `Unresolved` when the transcript does not support a reliable conclusion.

Never fill a gap with general knowledge without marking it as interpretation.
