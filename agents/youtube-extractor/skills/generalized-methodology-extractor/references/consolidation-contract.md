# Consolidated methodology contract

Consolidation combines completed per-video methods, not raw transcript fragments. De-duplicate equivalent steps while preserving differing prerequisites, sequencing, and scope.

Every generalized rule must map to one or more video IDs and timestamps. Represent material disagreement directly. Prefer conditional branches over forcing incompatible recommendations into one rule.

The result must separate source consensus, source-specific variants, agent synthesis, and unresolved questions.
